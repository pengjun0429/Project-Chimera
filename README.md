# 🧬 Project Chimera (奇美拉計劃)

> **這是一個會自我演化的網頁。** > 透過 GitHub Actions 與 Gemini AI，每天（或手動）對自己的基因（HTML）進行突變。

---

## 🚀 專案狀態
- **當前世代：** 自動更新中...
- **演化動力：** `Gemini`
- **執行環境：** `GitHub Actions` + `Python 3.9`

---

## 🧬 演化機制
本專案利用 AI 的創造力，不斷修改 `index.html`。
1. **觸發：** 每天凌晨 00:00 (UTC) 或由「使用者」手動觸發。
2. **分析：** 讀取目前的網頁結構與樣式。
3. **突變：** Gemini AI 根據當前基因，隨機加入新功能、3D 特效、小遊戲或賽博龐克視覺風格。
4. **重生：** 自動 Commit 並 Push 回儲存庫，完成一代演化。

---

## 🛠️ 如何手動加速進化？
若「使用者」等不及每日的自然演化，可以依照以下步驟：
1. 前往本 Repo 的 **[Actions]** 分頁。
2. 在左側選擇 **`Auto-Evolve Website`**。
3. 點擊右側的 **`Run workflow`** 按鈕。
4. 重新整理你的 GitHub Pages，見證奇蹟。

---

## 📜 基因序列 (檔案架構)
* `index.html`: 網頁主體（不斷變異中）。
* `evolve.py`: 進化的核心腳本。
* `.github/workflows/evolve.yml`: 自動化排程器。
* `requirements.txt`: 必要的 Python 基因組。

---

**⚠️ 警告：** 由於演化過程完全隨機，本網頁可能會在某個世代變得極度華麗，也可能在下一秒變得完全無法理解。這就是演化的樂趣。
